# Freigegebene Programm-Grafiken

Der Schriftzug verwendet ab 0.3.30 die unveränderte Orbitron-Schrift unter SIL Open Font License 1.1, nur der Name wird per CSS kursiv dargestellt. Schriftdatei und Lizenz unter `assets/fonts/`; Quelle https://github.com/google/fonts/tree/main/ofl/orbitron. Die Schrift ist eine stilistische Annäherung an das Rasterlogo, keine aus dem Logo extrahierte Originalschrift.

Übernahme aus dem von Sarevoc am 16.11.2026 freigegebenen Paket
`Sarevocs-CCU-Planer-Logo-und-Icons.zip`. Prüfsummen und Zuordnung stehen in
`approved-assets.json`. Die Dateien sind unverändert kopiert, ohne neue Ränder,
Skalierung oder Farbvarianten.

- `app.png`: Hauptlogo aus PROGRAMM, mit erhabenem Chromkreuz im Lorbeer;
  Seitenleiste und Verbindungsdialog.
- `app.ico`: PROGRAMM/ICO/Program.ico; Fenster, EXE und künftige Installer.
- `tray.ico`: exakt TRAY/CCU-Tray-Study-v2.ico; unveränderte Tray-Zustandslogik.

Die Alternative ohne Kreuz ist kein Standard. `app.svg` bleibt nur als historische
Quelle für ältere Vergleichsvorschauen erhalten und wird nicht mehr ausgeliefert.
Vorschauskripte dürfen die freigegebenen Dateien nicht neu erzeugen oder überschreiben.
Diese Übergabe ändert keine Lizenzregelung.
